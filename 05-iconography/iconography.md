# 05 — Iconography

> 图标是信息符号，不是装饰插画。

## 默认风格

`Rounded Geometric Iconography`：简洁几何、适度圆润、均匀 Stroke、不幼态、不锋利、不复杂。

## 尺寸与状态

```text
16  Compact
20  Standard Small
24  Standard
28  Large
32+ Feature
```

普通 UI 以 20 / 24 为核心。图标线宽保持统一的视觉重量；同一 Toolbar 不应同时出现极细与极粗图标。

```text
Regular → 普通 / 可用
Filled  → Selected / Active / 更强视觉重量
```

## 材质关系

Solid 上的图标像精确印刷，清晰、稳定、低装饰；Glass 上的图标采用 `Etched Ink` 语言，像浅浅蚀刻进入玻璃，再填入 Ink，但不可牺牲识别度。

## 平台策略

Apple 优先系统符号逻辑，Android / HyperOS 优先平台熟悉图标，Windows 遵循桌面交互习惯。Lumina 要求语义和视觉重量一致，不要求所有系统使用同一个文件。

## 禁止事项

无意义渐变、强烈 3D、混用多套图标库、所有图标都加背景圆圈，或为了品牌感重画所有系统常用符号。
