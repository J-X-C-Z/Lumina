# 07.5 — Dashboard / Settings / Form

## Dashboard

避免 20 个一样的圆角 Card。用大型 Solid Surface、Scoring、Embedded Regions、Typography 和少量 Cards 建立结构。

## Settings

优先 `One Solid Section + Scored Rows`；Switch 使用 Flowing Glass Thumb。不要每个设置项都生成一张 Card。

## Form

```text
Label
  ↓ 8
Recessed / Solid Input
  ↓ 4–8
Helper / Error
```

不同 Field 之间约 16–24，不同 Form Section 约 32–40；Submit 使用 Flowing Glass。
