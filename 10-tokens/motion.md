# 10.5 — Motion Tokens

```text
motion.instant     80–100ms
motion.fast        120–160ms
motion.standard    180–240ms
motion.slow        280–360ms
motion.expressive  400–550ms

motion.ease.standard
motion.ease.enter
motion.ease.exit
motion.ease.solid
motion.ease.fluid
```

组件动作语义：`motion.hover / press / focus / select / expand / collapse / page-enter / page-exit / ripple / trace / morph`。表达性动作必须支持 Reduce Motion 降级。
