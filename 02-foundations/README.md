# 02 — Foundations

02–05 是 Lumina v0.1 的成熟方案基线：先提供稳定、可用、跨平台的默认值，再通过真实项目逐项修订。

- [Color — 色彩](color.md)：中性为底，有目的地强调。
- [Typography — 排版](typography.md)：先组织信息，再塑造风格。
- [Spacing & Layout — 空间与布局](spacing-layout.md)：用空间表达关系。
- [Shape — 形状](shape.md)：柔和的几何，精确的结构。

Foundation 只定义通用视觉基础；材质的厚度、折射、层级和组合见 [03 — Materials](../03-materials/README.md)。
