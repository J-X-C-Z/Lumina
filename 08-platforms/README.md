# 08 — Platform Adaptation

> **Same language, different behavior.**  
> 统一设计语言，不机械复制同一套 UI。

所有平台共享 Philosophy、Color Logic、Typography Hierarchy、Spacing Logic、Material Language、Topography、Motion Personality 和 Icon Semantics；布局、系统控件、窗口行为和手势由平台决定。

- [Android / HyperOS](android-hyperos.md)
- [Windows](windows.md)
- [Web](web.md)
- [Watch / Vela](watch-vela.md)
- [Accessibility](accessibility.md)

[Flutter 当前实现与验收](flutter.md) 是本轮 v0.3 修订的主要实现依据。平台建议是适配目标；只将 [STATUS](../STATUS.md) 中有证据的部分计为已验证。
