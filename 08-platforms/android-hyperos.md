# 08.2 — Android / HyperOS

保持 Android Back、系统手势、OEM Window / Permission 行为和 Dynamic Layout；在此之上引入 Lumina Material。

大屏不应无限横向拉伸组件，应根据空间使用 Navigation Rail、Drawer 或多栏结构；信息密度随容器变化，而不是只缩放手机布局。保持 Lumina 的 Radius Hierarchy、Concentric Logic 和 Shape Personality。

## 系统触觉

使用系统效果与用户设置，不因 OEM 马达能力强制自定义波形。导航选择与重复项去重已有 HyperOS 真机执行记录；不能把单设备结果扩大到全部机型或最新动效性能。语义与宿主接线见[触觉](../04-motion/haptics.md)。
