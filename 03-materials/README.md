# 03 — Materials

Lumina 的材质不是装饰皮肤，而是界面空间和交互语义的一部分。

- [Flowing Glass — 流光玻璃](flowing-glass.md)：交互、导航、临时浮层。
- [Solid — 固态材质](solid.md)：文字、数据、任务、消息等内容。
- [Surface Deformation — 表面地形](surface-deformation.md)：Embedded / Raised / Recessed / Scored。
- [Elevation — 空间层级](elevation.md)：Canvas 到 Overlay 的 L0–L6。
- [Material Composition — 材质组合](material-composition.md)：推荐、限制和页面面积控制。

核心语法：

```text
Solid carries content.
Flowing Glass carries interaction.
```
