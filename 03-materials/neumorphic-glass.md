# 轻拟态、磨砂与玻璃夹层

2026-10-31 基线。轻拟态是现有 Lumina 的外观分支，保留 Solid 的稳定承托和克制的 2.5D 深度，不改变组件语义。

## 主题选项

| Flutter 选项 | 默认值 | 作用 |
| --- | --- | --- |
| `liquidGlass` | false | 既有清透、无颗粒外观 |
| `neumorphic` | false | 同一底材中的凸起与内凹，使用成对柔和明暗阴影 |
| `neumorphicGlass` | false | 与 `neumorphic` 及交互表面的 `glass` 配合，启用磨砂井与清透盖层 |
| `highPerformanceMode` | true | 独立的绘制成本选择，保留材质终态及轻量连续动效 |

这些是 `LuminaThemeData` / `LuminaTheme` 的配置，不是共享 JSON 新增字段。轻拟态分支优先于既有清透绘制；局部 `frosted` 表面可退出轻拟态分支。不能假定所有开关组合都会叠加视觉效果。

## 同材质凹凸

Canvas、凸起面和凹面属于同一底材，用统一左上环境光、柔和外阴影/内阴影与边缘表达深度。凸起不是另一张悬浮白卡；凹槽不额外增加一圈外框。轻拟态允许直接在底材挖槽，旧雕刻分支才在无 card host 的凹面外补承托卡。

非轻拟态表面的自动承托与 `LuminaCardHost` 继续有效。标题肩部按首行文字实测宽度和缩放计算，不能用卡片宽度的固定比例代替。层级、文字与焦点辨识度优先于阴影的细腻程度。

## 玻璃夹层

```text
同材质底板 → 凹陷磨砂井 → 可读内容 → 清透盖层
```

`LuminaGlassWell` 承托内容，`LuminaGlassCoat` 只绘制盖层并忽略命中测试。文字置于磨砂层之后、盖层之前，不对文字整体模糊；实际交互、焦点和语义仍由原控件持有。三层使用同一圆角与对齐几何。

井保持内凹几何，盖层提供薄边、厚度和连续压力反馈，不是新增外卡。选择控件的夹层可随选择位置移动；不要把所有材质分支都描述成静止井＋凸起放大镜。

## 成本与降级

常规模式的夹层井仅对自身静态绘制做 sigma 4 的 `ImageFiltered`，没有采样背后页面。高性能模式使用缓存的磨砂井图片（最高 2x 栅格、边长上限 1024，缓存最多 48 项 / 12 MiB）。高性能阴影使用九宫格遮罩（最多 64 项 / 8 MiB）；保留凹凸阴影，不改成平面。

连续按压保持凹/凸遮罩的尺寸与模糊半径固定，以透明度混合，避免每帧生成纹理。内容微纹理使用共享静态 tile，禁止为每行材质加入实时模糊或常驻装饰 ticker。缓存数量是当前实现上限，不能据此承诺某设备帧率。

降低透明度或高对比度时，井使用不透明承托、盖层退出；内容、焦点及选中态仍可辨认。减少动态效果直接呈现压力终态，选择和操作继续有效。
