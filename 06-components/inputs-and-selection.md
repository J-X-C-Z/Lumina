# 06.2 — Inputs & Selection

## Input / Search

推荐：`Solid Input Well + Text + Flowing Glass Actions`。文本区域稳定、可读，Clear、Dropdown、Voice、Submit 等操作区域活跃。Search 是 `Input + Navigation Control`，可用 Solid / Recessed Search Field + Glass Search Actions。

## Switch

```text
Solid / Recessed Track + Flowing Glass Thumb
```

Off 时玻璃活性降低；On 时获得 Accent Tint。状态不能只用颜色表达。

## Slider

```text
Recessed Track + Flowing Glass Handle
```

拖动时 Handle 可有轻微流体拉伸，但不应制造明显装饰动画。

## Checkbox / Radio

保持简洁、高识别度和高可访问性。Selected 后可出现轻微 Glass / Accent 特征，但不要过度材质化。

## Chip / Filter

默认使用 Capsule。未选为 Solid / Neutral，选中为 Soft Flowing Glass。一个页面不应让所有 Button、Input、Navigation 和 Tag 都变成 Capsule。
