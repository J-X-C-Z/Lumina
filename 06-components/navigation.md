# 06.4 — Navigation

Navigation 属于控制界面而不是内容，因此优先使用 Flowing Glass：Bottom Navigation、Tab Bar、Floating Sidebar Control、Toolbar、Command Bar。

Sidebar 主体可使用 Solid Base；Selected / Control 使用 Glass，形成 `Solid Architecture + Glass Interaction`。

Tab / Segmented Control 推荐：

```text
Recessed Track + Flowing Glass Selection
```

Selection 在 Track 内平滑移动。Desktop 的 Navigation 可以更紧凑，Mobile 的 Navigation 应保留清晰的大命中区，Watch 只保留最少层级。
